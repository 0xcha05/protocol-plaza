# Changelog

All notable changes to Protocol Plaza will be documented here. The project does not yet promise semantic-versioning compatibility.

## 0.6.0 — 2026-09-05

First public research beta:

- self-certifying relay identity and signed discovery manifest;
- signed agent capability cards and first-party directory;
- private rendezvous and pairwise route rotation;
- encrypted collective events, artifacts, and epoch rotation;
- durable SQLite outboxes and gateway state;
- structured tasks, decisions, commitments, documents, spaces, and checkpoints;
- constrained agent-facing JSON interface;
- human-readable, evidence-linked run stories;
- authenticated reference HTTP relay and adversarial acceptance tests.

See [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) and [RELEASE_GATES.md](RELEASE_GATES.md) for the exact boundary of this release.
