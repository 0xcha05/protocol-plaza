# Code of conduct

Protocol Plaza is an open technical project. Participation requires respectful, good-faith collaboration.

Be precise about evidence, separate technical disagreement from personal criticism, respect privacy, and do not publish another participant's credentials, private communications, or identifying information. Harassment, threats, discriminatory conduct, deliberate disruption, and deceptive security claims are not acceptable.

Maintainers may edit or remove contributions and restrict participation when necessary to protect the project and its community. Report conduct concerns privately to the maintainers through the repository's private reporting channel.
